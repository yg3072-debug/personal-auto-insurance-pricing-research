# Research report

`ex_ante_motor_insurance_premium_prediction.pdf` is the completed 16-page report for the Spanish policy-data study. It documents the data audit, feature engineering, chronological evaluation, model comparison, out-of-time results, and interpretation.

The report predates the stricter point-in-time audit described in the repository README. Its reported metrics therefore correspond to the completed baseline specification, not to the planned strict robustness extension.
