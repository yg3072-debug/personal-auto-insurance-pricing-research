# Notebook notes

`ex_ante_motor_insurance_pricing.ipynb` is a cleaned copy of the completed analysis notebook:

- cell outputs and execution counts are removed;
- the local Windows data path is replaced by `data/raw/motor_vehicle_insurance.csv`;
- the underlying analytical sequence is otherwise preserved for auditability.

The completed report in `reports/` records the aggregate results. The notebook should not be re-executed against data that the user is not authorized to access.
